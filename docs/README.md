### Beschreibung

Das Apple HomeKit-Modul ermöglicht die Steuerung von IP-Symcon-Geräten über die Home-App und Siri. Der HAP-Stack ist nativ in PHP implementiert — kein externer Prozess, kein Polling.

Eine vollständige Anleitung zur Installation und Einrichtung sowie eine Übersicht aller unterstützten Gerätetypen findet sich im [GitHub-Repository](https://github.com/JosVanHaag/IPS-Homekit).
